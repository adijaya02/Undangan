UNDANGAN PERNIKAHAN — FILE TERPISAH

Isi folder:
- index.html     : halaman pembuka undangan
- undangan.html  : halaman utama undangan
- style.css      : desain untuk halaman utama
- script.js      : countdown, menu, RSVP WhatsApp, salin rekening/alamat
- assets/        : tempat menyimpan foto atau musik milik Anda

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka index.html dengan Chrome.
3. Klik "Buka Undangan" untuk berpindah ke undangan.html.

PENTING UNTUK DISESUAIKAN
Buka script.js lalu ganti:
- weddingDate (tanggal/waktu acara)
- whatsappNumber (nomor WhatsApp dengan kode negara, tanpa +)
- accountNumber (nomor rekening)
- giftAddress (alamat hadiah)

Di index.html dan undangan.html, ubah nama, tanggal, alamat, jam acara, URL foto, dan tautan Google Maps sesuai informasi yang benar. Nama, foto, alamat, dan nomor rekening di dalam file saat ini hanyalah contoh.
Tanggal 23 Agustus 2027 jatuh pada hari Senin, bukan Sabtu. Pastikan hari/tanggal diperbarui sesuai acara sebenarnya.
Foto dan font di contoh memakai URL eksternal, jadi memerlukan koneksi internet. RSVP saat ini membuka WhatsApp; belum menyimpan data ke database.
